description: Package a completed or blocked NoBugs task for another teammate, agent session or PR review.
---
다른 담당이나 다음 세션이 이어서 작업할 수 있게 결과를 정리할 때 사용합니다.

[인수인계 양식](../../../orchestration/handoff-template.md)에 작업 ID, 브랜치·커밋, 실제 변경, 실행한 확인과 결과, 미연결·미검증 부분, 다음 담당의 첫 행동을 기록합니다. 막혔다면 재현 조건과 필요한 입력을 적고 완료로 표시하지 않습니다.

문서·스키마·예시 변경과 실제 기능 구현을 구분합니다. PR에는 reviewer가 결과를 판단할 수 있는 근거를 남깁니다. 양식을 작성하는 것이 다른 채팅에 메시지를 보내거나 PR을 병합하는 권한을 부여하지는 않습니다.

사람 자리·개발 역할·시험 ID를 각각 명시합니다. 담당별 준비 회신 1회와 최종 회신 1회를 기본으로 하고 오류·조건 변경은 즉시 전달합니다. 확인 범위/근거 종류/관측 구간/미확인/다음 담당/필요 입력을 한 번에 넘기며, 정보 변화 없이 이미 받은 확인을 반복 요구하지 않습니다. 연결 당사자 A↔D, B↔D, C↔D가 직접 대조하고 조율자는 공통 현황·의존성을 관리합니다. 실제 발송에는 사용자의 명시 지시가 필요합니다.

공동 연결 작업이 막히면 오류 사실은 즉시 알리고, 해결되지 않은 문제는 발견 후 늦어도 20분 안에 `시험 ID·실행 버전·시각 / 마지막 성공 단계 / 기대 결과 / 실제 응답·로그 / 필요한 도움`으로 증거를 묶습니다. 정상 사용자 오차단·예상 밖 조치·비밀값 노출은 즉시 중단·공유 대상으로 두며 20분을 기다리지 않습니다. 공유용 초안과 실제 발송을 구분하고, 이 규칙 자체를 메시지 자동 전송 권한으로 해석하지 않습니다.

요청 자체가 의심되면 처음부터 실제 전송 헤더·본문·Content-Type과 수신 결과를 대조합니다. 비밀번호·토큰·쿠키는 제거하고 본문도 합성 또는 비식별 증적만 사용합니다. 대상 호출 성공 뒤 기록 실패나 응답 유실은 원래 실행 ID·요청 키와 현재 상태부터 대조하며, 원인을 모른 채 요청을 재전송하지 않습니다. 확정한 통합 커밋과 실제 빌드/게시 버전, 재빌드 담당·결과를 한 묶음으로 인계합니다.

원문 수신/정규화, 정의 없음/조회 0건, dry_run/실제 호출/효과, 저장소 미가동/가동 중 티켓 0건을 구분합니다. 최신 상태는 `docs/PROGRESS.md`의 기존 편집 담당 A가 요약하고 다른 담당은 상세 이력·실행별 증적을 남깁니다. 접근할 수 없는 학원 PC 경로는 원본 미열람으로 남기고 사본을 재구성하지 않습니다.

lab-check 보고서 묶음이 있으면 [팀 실행 안내](../../../docs/lab-check-team-run.md)에 따라 `python tools/lab_check.py status --bundle <묶음 경로> --seat <사람 자리>`로 manifest와 비교 범위를 검증한 결과를 읽습니다. 같은 실행 ID·묶음 경로를 근거로 전달하고 다른 LLM 답변을 반복 복사하지 않습니다. `out_of_scope` 자리에 이 좁은 대조의 회신을 요구하지 않습니다. status의 종료0은 조회 성공이며 장비 준비/시험 완료가 아닙니다. 현재 파일 수집은 오프라인 대조이고 실제 준비·효과·원복 근거를 대신하지 않습니다.
