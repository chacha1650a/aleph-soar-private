# 기획서 합의본 피드백 (chacha1650a)

기준: PR #10 `docs/proposal-sections`의 `team_docs/기획서_합의본.md` 최신 커밋 `2a6e2da`(10/19, 684줄)와 교차검토 PDF(`ef3e546` 기준)를 대조했다.
범위: 문서 읽기와 대조만 했다. 설치·연동·시험은 하지 않았다.
D(S12) 자리에 관한 내용은 이 문서에 넣지 않았다. S12 관련 확인 사항은 [통합 문서](통합-교차검토와S12계획-chacha1650a.md)와 [S12 진행계획](S12-진행계획-D-chacha1650a.md)에 따로 있다.

## 2. 남은 확인 사항 (D 제외)

교차검토 PDF의 "추가 확인" 5개 가운데 D가 직접 맡지 않는 부분과, 최신 기획서를 읽고 새로 본 점이다.

| # | 위치 | 확인할 내용 | 담당 |
| --- | --- | --- | --- |
| 1 | ⑤ 5.9 순서 조건 | S4 "실패 뒤 성공", S8 "스캔 뒤 실패"의 순서를 요구할지 10/21에 정해야 한다. 5.2 입력표에 "순서 반대" 행은 있지만 기대값이 "순서를 요구하기로 정하면 미발동"이라 이 결정에 따라 정해진다. 정한 뒤 창 밖·한 종류 누락 입력도 케이스별로 명시한다. 사용하는 Graylog 버전이 순서를 판정할 수 있는지는 5.10 S4 사전 시험에 있지만 S8에는 없다 | A·B |
| 2 | ③ 망 분리 정책 | pfSense 차단·state 제거 절차는 있으나 LAN 배정, anti-lockout, 규칙 우선순위는 적혀 있지 않다(PDF 06). 공격 IP로 한정한 state 제거 뒤에도 관리·자동화 연결이 유지되는지 확인한다 | B |
| 3 | ④ 로그 수집 | filterlog 출발지 정규화는 문장으로만 있다. 실제 IPv4·IPv6 샘플로 필드 위치와 action=block 방향을 확인해 정규화 예시를 고정하면 좋겠다(PDF 07) | B |
| 4 | ④ S7 파일 키 | 웹 루트 기준 상대 경로로 묶는데 여러 자산을 감시하면 같은 상대 경로가 충돌할 수 있다. `asset_id`를 키에 넣을지 정하자(PDF 04) | C |
| 5 | ④ 인시던트 관리 | 티켓 묶기는 A가 username, 탐지는 S1이 username + src_ip다. 같은 계정의 다른 출발지가 한 티켓에 들어갈 때 출발지별 차단이 빠지지 않는지, 재전송·재시도·동시 실행에서 중복이 없는지 확인한다. 본문에는 n8n 재시도 횟수를 기록한다는 내용은 있지만 이 경우의 중복 방지 기준은 없다(PDF 09) | A |
| 6 | ⑥ 시연 범위 | 라이브는 자리별 필수 케이스 하나씩인데 평가 기준의 적용 단위(케이스 ID별인지 자리별인지)를 강사님께 확인하는 계획이 최신 본문에는 보이지 않는다(PDF 10은 강사 확인 사항으로 유지한다고 적음). 10/21 안에 질문할 사람과 방법을 정하자 | 전원 |
| 7 | ⑥ 일정 | 반복 측정 60회가 11/02~11/03에 들어가는지 자리별 총 소요를 합산해 일정표에 적으면 좋겠다. 지금은 S1 5시간만 계산돼 있다 | 전원 |
| 8 | 제출 전 정리 | `(팀 확인)`·"합의 전 제안이다"·작성 현황·"제출 전 정할 것" 표를 10/22에 빼야 한다. 최신 본문에 해당 표시가 있는 줄이 6줄 남아 있다 | 전원 |

## 3. 장점으로 유지하면 좋은 것

- 필수 케이스마다 효과 확인 → 원복 → 보강 전후 비교까지 묶은 점(공지의 평가 기준과 맞다).
- "문서 반영"과 "시험 통과"를 구분해 미검증을 숨기지 않는 표기.
- S7을 자동 복구 유형으로 따로 둔 것(최신 커밋 `2a6e2da`).
- 계획값과 확인한 값(PC 사양 10/19)을 구분한 서술.

## 4. 이 문서의 한계

- 기획서는 계속 바뀌고 있어(10/19 하루에 커밋이 여러 개) 위 확인은 `2a6e2da` 시점이다.
- 교차검토 PDF는 `ef3e546` 기준이라 그 뒤 반영된 항목이 PDF에는 "추가 확인"으로 남아 있을 수 있다. 위 2~5번은 최신 본문에서 해당 문구가 없음을 확인했지만, 다른 곳에 적혀 있을 가능성은 배제하지 못했다.
- 랩 시험은 하지 않았다.
