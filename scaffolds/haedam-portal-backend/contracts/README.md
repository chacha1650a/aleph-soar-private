# 사용하는 계약의 출처

원본 저장소: `NoBugs-Aleph/aleph-soar-capstone`.
원본 경로: `docs/API-CONTRACT.md`, `contracts/`.
적용한 원본 커밋: **미지정 — 소비할 계약 합의 후 기록**.
복사한 파일·사용 API·이벤트: **아직 없음**.

새 저장소에서 필요한 계약만 복사하고 파일별 원본 경로·버전을 여기에 적는다. 요청·응답·오류·인증·이벤트 필드·대응·원복 결과를 원본과 맞춘다. 기존 스키마가 새 익명 요청 등을 표현하지 못하면 구현 전에 원본 변경을 조율한다.

변경은 원본 문서·스키마·예시·검증과 프론트·백엔드·관제 소비자를 함께 맞춘다. 스키마 검증 통과는 실제 탐지·차단·티켓·원복 성공의 증거가 아니다.
