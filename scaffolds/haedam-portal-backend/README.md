# 해담시청 민원포털 · 백엔드

시민의 목소리를 담다, 해담시청.

목표 저장소: `haedam-portal-backend`.
현재 상태: **문서·폴더 스켈레톤만 준비됨. 실행 가능한 Flask 앱 없음.**

## 폴더 구조

```text
AGENTS.md                 # 작업 규칙 진입점
CLAUDE.md                 # AGENTS.md 불러오기
CODEX.md                  # 보조 안내
docs/PROJECT-RULES.md      # 공통 제약 배포용 복사본
contracts/README.md       # 계약 원본·버전·사용 범위
src/haedam_portal/
  auth/                   # 인증·역할·세션
  petitions/              # 민원 생성·조회·처리
  admin/                  # 승인된 계정 관리
  integration/            # 이벤트·대응·원복 연결
tests/                    # 인증·권한·데이터·대응 검증
```

빈 폴더의 `.gitkeep`은 첫 실제 파일을 추가할 때 제거할 수 있다. 초기화 작업에서 앱 팩토리·설정·모델·의존성 잠금·마이그레이션을 추가한다. 아직 `create_app`이나 테스트 파일이 없으므로 기존 capstone의 실행 명령을 그대로 사용할 수 있다고 가정하지 않는다.

## 최초 연결·인수

1. 원본 계약에서 프론트와 사용할 API·인증·오류·권한표를 확정한다.
2. 격리된 환경에서 합성 계정·민원을 준비하고 로그인·저장·조회·처리를 구현한다.
3. 타인 민원·무권한 처리 거부, 로그아웃·세션 만료, 재시작 후 데이터 유지를 확인한다.
4. 계약 형식의 이벤트 발생과 민감 데이터 제외를 검증한다. SIEM 도착 여부는 별도로 확인한다.
5. n8n 대응 API는 관리망·호출자 인증·대상 제한·실제 효과·원복을 확인한 뒤 연결한다.

실행 방법·테스트 명령은 구현하면서 실제 재현한 내용으로 채운다. Flask 개발 서버·디버그 모드를 외부 실습 배포용 실행기로 사용하지 않는다.
