# 사용하는 계약의 출처

원본 저장소: `NoBugs-Aleph/aleph-soar-capstone`.
원본 경로: `docs/API-CONTRACT.md`, `contracts/`.
적용한 원본 커밋: **미지정 — 소비할 계약 합의 후 기록**.
복사한 파일·사용 API: **아직 없음**.

새 저장소에서 필요한 계약만 복사하고 파일별 원본 경로·버전을 여기에 적는다. API 경로·권한·응답·오류를 원본에서 확인하고 백엔드와 같은 커밋을 사용한다. 프론트 전용 임시 응답을 공통 계약으로 간주하지 않는다.

변경은 원본 문서·스키마·예시·검증과 프론트·백엔드 소비자를 함께 맞춘다. 계약이 맞아도 실제 API·탐지·대응 연결이 완료된 것은 아니다.
