사용자가 방금 제안한 참고 사이트와 화면 구성을 Claude에게 검토받으라고 요청했습니다. 이전 후보 투표를 새로 시작하지 말고 이번 자료를 독립 검토해 주세요.

먼저 AGENTS.md와 docs/17-reference-sites-review.md를 읽고, 필요한 부분만 docs/14-smart-factory-roadmap.md, docs/15-market-research.md, docs/16-market-research-rereview.md, docs/API-CONTRACT.md에서 확인해 주세요.

읽기와 공개 웹 자료 확인만 수행하세요. 파일 수정, 명령 실행, 에이전트 추가 실행, 커밋·푸시·PR 생성, 메시지 발송, 제품 가입·데모 신청, 인프라 실행은 요청 범위가 아닙니다. 실제 검토를 수행하고 최종 응답을 한국어 Markdown으로 반환해 주세요. 작업 기록 파일은 요청한 Codex가 응답을 받은 뒤 저장합니다.

docs/17의 검토 질문 1~7에 답해 주세요. 확인된 조건인 4인·2주, 보안 도구 6종의 사용 예정, 이후 다른 팀과의 공방전 계획은 다시 질문하지 마세요. 미정인 공방전 규칙·배치·평가 요건은 판단 보류 항목으로 기록하세요.

가능한 경우 공식 출처로 비교 내용을 검증하되, 페이지 열람과 실제 제품 동작 시험을 구분하세요. 웹 접근이 막힌 자료는 확인하지 못했다고 명시하고, 제공된 설명에 근거한 판단은 그렇게 표시하세요. 출처 URL은 해당 판단 가까이에 Markdown 링크로 남겨 주세요.

최종 응답 형식:

1. 검토 범위·읽은 파일·실제 확인한 웹 자료와 확인 한계.
2. 최종 판정: 수용 / 수정 권고 / 판단 보류와 핵심 이유.
3. 우선순위별 지적: 중요도, 문서 위치·주장, 이유, 구체 수정안.
4. 참고할 사이트 상위 3개와 가져올 요소·제외할 요소.
5. 2주 범위의 화면·역할·도구 책임 연결과 공방전 증적.
6. 추천하는 한 문장 주제·최소 시연 흐름·남은 결정.

검토자가 파일을 바꾸거나 팀이 주제를 채택했다고 쓰지 마세요. 구현·제품 연동·공방전을 실행한 것으로 주장하지 마세요.
