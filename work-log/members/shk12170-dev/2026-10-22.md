## D에 550(변경) 경보만 안 오는 문제 (10:45~11:15)

- 증상(D 확인): `zz_d_103950`의 554·553은 D Graylog에 도착, **550은 없음**. C 연습 Graylog에는 3건 모두 도착.
- 크기: 554 약 1,121바이트, 553 약 1,238바이트, **550 약 2,078바이트**(변경 전·후 해시와 diff 포함). 실제 웹 파일이 바뀌면 diff 때문에 더 커질 수 있음.
- 경로 MTU: C → VPN 서버(10.250.0.1) `ping -f -l` 1400 통과, 1472는 "fragmented but DF set" → 한 패킷에 실을 수 있는 크기 약 1,400바이트대.
- 크기별 UDP 시험(10:51:47, `zz_size_105147_*`): D에 **1000·1300·1400 도착, 1500·2000 미도착**(D 확인). D가 본 출발지는 `172.23.0.1`(D 쪽 Docker 게이트웨이).
- **결론:** 약 1,400바이트를 넘어 IP 조각(fragment)으로 나뉜 UDP가 C → VPN → D 경로 어딘가에서 버려짐. 550 미수신 원인. 정확히 어느 구간(pfSense·OpenVPN·D Windows·D Docker)에서 버려지는지는 미확인.
- 영향: 판정 핵심인 550(변경)이 빠지면 S7 탐지 불가. **포털 GELF UDP 등 다른 자리 로그도 1,400바이트를 넘으면 같은 문제** 가능.
