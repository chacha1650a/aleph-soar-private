## 문제와 해결

- **전송 지연:** 10/23 아침 C 수업 Graylog(`gl-*`)가 꺼져 있어(10/22 저녁 종료) Wazuh `csyslogd`가 수업·연습 전송 대상 `gl-graylog`를 찾지 못함(`(1216) Unable to connect to '[gl-graylog/]:5514/udp'`). 경보마다 이 대상에서 기다리느라 팀 경로(중계 → D)도 경보당 약 1분씩 밀림 → S7 MTTD 목표(≤ 60초)에 영향. 수업 Graylog를 켜서 해소, 16:49 manager 전송 설정에서 수업·연습 블록을 빼서 근본 정리. **수업 Graylog를 끈 상태의 팀 경로 지연은 아직 재측정 못 함**(연습 폴더가 15:14 재생성으로 사라짐, 디렉터리를 나중에 만들면 realtime 감시가 걸리지 않아 manager 재시작이 한 번 더 필요 → A 시험 파일로 확인)
- **방화벽:** VPN 대역만 허용 규칙을 넣어도 유선(192.168.3.x)에서 1514·1515가 열림. Docker Desktop Backend Public 허용 규칙이 출발지 제한 없이 열고 있었음 → 차단 규칙 `Wazuh block non-VPN` 추가(차단이 허용보다 우선). 원복 `Remove-NetFirewallRule -DisplayName "Wazuh block non-VPN"`
- **비밀번호 입력:** `wazuh` 관리자 비밀번호 변경 뒤 로그인 401 → 붙여넣기(Ctrl+V) 값이 의도와 다르게 저장된 것으로 추정 → 두 번 입력 비교·제어문자 검사 스크립트로 재설정, 별도 입력으로 로그인 확인
- **세션 간 파일 충돌:** 공유 폴더를 여러 세션이 같이 써서 브랜치 전환·스테이징 영향 → 티켓 저장소 파일은 D 협업 세션만, 그 밖의 통합 작업은 별도 worktree에서
- **같은 일지 파일이 두 PR에:** 이 일지(#52)와 `docs/s7-evidence-1022`(#53)가 `2026-10-22.md`·`2026-10-23.md`를 둘 다 고침 → 병합 때 충돌. 이 파일을 최종본으로 두고 #53에서는 두 일지를 빼는 쪽으로 정리 필요
