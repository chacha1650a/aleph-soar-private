## D에게 전달할 내용 (10/20 연습 결과)

1. Wazuh `syslog_output`은 UDP만, 메시지 형태는 `<132>… wazuh-manager ossec: {JSON}` → **Raw/Plaintext UDP 입력** 권장(514·5140 피함). D PC 호스트 공개 + C 출발지만 허용.
2. 파싱: 수업 규칙 `wazuh: parse alert json`(stage 0) + `wazuh: fim path safe`(stage 1) 재사용 → `wazuh_` 접두 필드. stage에 규칙이 없으면 오류 없이 아무것도 안 됨. 스트림은 match input + Default Stream 제외.
3. 실측 필드: `wazuh_rule_id`(554 추가 / 550 변경 / 553 삭제), `wazuh_syscheck_event`, `wazuh_rule_level`(554=5, 550=7), `wazuh_syscheck_path`·`wazuh_file`(절대 경로), `wazuh_syscheck_sha256_after/_before`, `wazuh_agent_id/name`, `wazuh_timestamp`.
