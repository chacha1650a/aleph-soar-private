## 문제와 해결

- 증상·원인: Wazuh manager 설정(`ossec.conf`) 변경이 반영되지 않음 — 설정 파일이 Docker 볼륨 안에 있어 호스트에서 수정한 내용이 컨테이너에 반영되지 않았음.
- 수정 내용·재확인 결과: 컨테이너 내부 파일을 직접 수정(`docker cp`/`docker exec`)해 해결, 이후 설정 반영 확인.
- 증상·원인: Wazuh 경보에 변경 내용(diff)이 표시되지 않음 — 컨테이너에 `diff` 바이너리가 없음.
- 수정 내용·재확인 결과: 별도 수정 없음. 탐지 판정이 해시 비교 기반이라 diff 부재가 판정에 영향 없다고 판단(설치 추가는 보류).
