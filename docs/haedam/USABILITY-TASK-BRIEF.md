# 10/19 포털 사용성 개선

- 사용자 지시: 실제 시민 신청→담당자 답변→시민 확인에서 재현한 네 가지 문제를 개선한다.
- 범위: frontend의 민원 신청·답변·목록·공통 이탈 경고·입력 오류·모바일 CSS와 회귀 테스트, backend의 입력 검증 오류, capstone의 선택적 오류 fields 계약과 예시. 기존 `codex/haedam-portal-mvp` Draft PR을 갱신한다.
- 인수: 시민 신청·담당자 답변의 링크 이동/뒤로 가기/로그아웃/새로고침 경고와 계속 작성·명시적 폐기, 저장 완료 시 정상 이동. 민원 원문을 브라우저 저장소에 넣지 않는다.
- 인수: 입력란별 한국어 오류·레이블 연결·오류 위치로 포커스, 서버 검증 실패 시 입력 유지. 오류 응답의 기존 code/message는 유지한다.
- 인수: 검색·분야·상태·페이지를 URL로 복원하고 상세 왕복·뒤로 가기·새로고침에서 유지한다. 320/390px에서 제목 14px·상태 12px 이상과 입력 안내, 가로 넘침을 확인한다.
- 제외: 서버 임시저장 API·DB 변경, 첨부파일, 보안 케이스 담당 재배정, 실제 외부 관제 연결. 새로고침 경고는 브라우저가 제공하며 모바일 앱 강제 종료까지 초안 보존을 보장하지 않는다.
- 연결: 공통 오류 계약은 양쪽 복사본·출처를 맞춘다. D의 기존 event/incident 소비자는 변경하지 않는다. 실제 dist 번들이 바뀌므로 C의 FIM 기준본은 승인한 정상 배포로 별도 갱신한다.
