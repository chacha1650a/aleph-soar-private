### S1 짧은 간격 입력의 근거와 미검증

- 탐지 조건은 같은 username + src_ip의 401이 **30분 안에 9건 이상**이라 간격과 무관하다. 9건을 2~3분에 넣어도 발동한다.
- 포털 로그인 속도 제한은 **출발지 IP당 최근 5분 로그인 시도 20건 이상이면 429**다(backend `f3faa1c` `auth/__init__.py` `LOGIN_RATE_LIMIT=20`, VM 배포본과 같은 커밋, 코드 읽기로 확인). 9건은 한도 밖이라 429가 나지 않는다.
- 첫 탐지는 Graylog 1분 실행 주기 때문에 9번째 입력 뒤 **최대 약 60초**(+수집 지연) 기다린다.
- **미검증:** 짧은 간격 9회를 실제로 돌린 적은 없다 → 11/4 리허설에서 B Kali로 1회 시험(시간 측정, 429 없음, 탐지·차단 확인).
- 라이브 회차도 계정·출발지를 새로 쓴다(B 11/04 확정: `zz_s1_1105_live01`·`.15`, 정상 `.12`). 결과표에는 "시연 회차"로 따로 적고 5회 측정에 섞지 않는다.
