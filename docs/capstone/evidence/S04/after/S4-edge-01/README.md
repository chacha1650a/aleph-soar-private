# S4-edge-01 (보강 후 경계 · 실패 4 + 성공 1 미발동, GELF TCP) — 현장 기록표

> **준비만 된 회차(11/03 A 작성, 일정 미정).** [S4-after-01](../S4-after-01/README.md)(실패 5 + 성공 1 발동)의 짝이다. 오프라인 재생 8/8만 있고 랩 실측은 없다.
> 시험 중에는 빈칸만 채운다. 시각은 **포털 VM·Graylog·n8n 기록 기준**. 비밀번호·`X-Response-Key`·세션 값은 적지 않는다.
> S4 조건은 같은 username + src_ip에서 10분 안에 401과 200이 **모두** 있고(`card(rule) > 1`) 합계 **6건 이상(`count() > 5`)**이다. 이 회차는 **401 4회 + 200 1회 = 5건**만 넣고 미발동을 확인한다.
> 판정 기한(리포트 4-9): 마지막 입력 뒤 **10분 창 + 검색 주기(1분) + 수집 지연**까지 관측한다. 그동안 같은 계정·출발지로 **아무 로그인도 더 보내지 않는다**(6번째 신호가 되면 발동).
