# S1-edge-01 (보강 후 경계 · 401 8회 미발동, GELF TCP) — 현장 기록표

> **재예약 회차.** 10/29에 계획했으나 포털 GELF UDP 유실로 미실행(B 결정 15:3x). 경계 시험은 "8건이 모두 도착했는데도 미발동"이어야 의미가 있으므로 TCP 전환(backend #8 `f3faa1c`, 10/30 배포·11/02 동작 확인) 뒤 **새 backend SHA·계정·출발지**로 진행한다. 10/29 계획값(`.16`·`zz_s1_1029_b8`)은 쓰지 않는다.

> 시험 중에는 빈칸만 채운다. 시각은 **포털 VM·Graylog·n8n 기록 기준**. 비밀번호·`X-Response-Key`·세션 값은 적지 않는다.
> S1 조건은 같은 username + src_ip의 401이 30분 안에 **9건 이상(`count() > 8`)**이다. 이 회차는 **정확히 8건**만 넣고 미발동을 확인한다. 9번째 요청은 보내지 않는다(B 도구 경계 모드).
> 판정 기한(리포트 4-9): 마지막 입력 뒤 **30분 창 + 검색 주기(1분) + 수집 지연**까지 관측한다. [S1-after-03](../S1-after-03/README.md)과 같은 시각에 시작하지만 계정·출발지가 달라 키가 따로다.
